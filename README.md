# I L Productions Studio Website

Official website for **I L Productions**, a 2D animation and motion design studio based in Randburg, South Africa. Built using HTML5, Tailwind CSS, and Lucide Icons.

---

## 🚀 Live Site
Visit the official studio website: [https://il-productions.com](https://il-productions.com)

---

## 🛠️ Stack & Technologies

* **HTML5** – Semantic single-page layout structure.
* **Tailwind CSS** – Utility-first CSS framework for custom cyan-blue visual effects, animations, and responsive styling.
* **JavaScript (Vanilla)** – Client-side single-page application (SPA) routing and interactive elements.
* **Lucide Icons** – Clean SVG icon rendering.
* **Vercel** – Hosting platform and custom domain deployment (`il-productions.com`).
